# WebLLM Adapters

[WebLLM](https://github.com/mlc-ai/web-llm) runs AI models locally in your browser using WebGPU.
These community adapters connect WebLLM to agent frameworks.

Models include Llama, Qwen, Gemma, and Phi. See the [model catalog](https://webllm.mlc.ai/docs/user/basic_usage.html#model-records-in-webllm)
for available models; features depend on the model.
